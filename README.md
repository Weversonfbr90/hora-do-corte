# Hora do corte

Um aplicativo para donos de pequenas barbearias que automatiza o agendamento de horários pelos clientes, sem interrupções e perdas financeiras no WhatsApp.

> **Status:** etapa 1, Design System (v0.1, em revisão). O app ainda não foi iniciado.

## Tecnologias

Next.js (App Router) · React · TypeScript · Tailwind CSS 4 · Lucide (ícones) · Manrope (fonte)

## Como rodar

Requer Node.js 20 ou mais novo.

```bash
npm install
npm run dev
```

Abra <http://localhost:3000/design-system> para ver a demonstração dos componentes.

| Comando | O que faz |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run typecheck` | Checagem de tipos |
| `npm run contrast` | Verifica o contraste das cores (WCAG 2.2 AA) |
